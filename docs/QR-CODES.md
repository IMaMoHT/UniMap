# QR-коди «Ви тут» — повна інструкція

Фізичний QR-код біля дверей відкриває UniMap і **одразу підставляє це приміщення
як точку старту**. Користувачу лишається обрати тільки «Куди».

---

## 1. Як це працює технічно

```
[QR на стіні]  →  https://unimap.example.com/?start=55
                                              └────┬────┘
                                                   │
                        SetARoute читає параметр через utils/deepLink.ts
                                                   │
                                    fromValue = "Кабінет 55", поверх = 1
```

Ніякого бекенду не потрібно: увесь стан живе в URL, а розбір — на клієнті.

### Підтримувані параметри

| Параметр | Синонім | Призначення | Приклад |
|---|---|---|---|
| `start` | `from` | Точка старту | `?start=55` |
| `to` | `dest` | Точка призначення (необовʼязково) | `?to=Ректорат` |
| `floor` | — | Початковий поверх | `?floor=2` |

Якщо задано і `start`, і `to` — маршрут будується автоматично одразу після
відкриття сторінки.

### Що можна писати в `start`

`resolveRoomIdentifier()` розпізнає чотири формати — беріть будь-який зручний:

1. **Номер кабінету** — `?start=55`
2. **id приміщення** — `?start=Ректорат`, `?start=library`
3. **id вузла графа** — `?start=f1_node_181`
4. **roomId вузла** — `?start=stairsmain1`

## 2. Покрокове впровадження

### Крок 1. Опублікуйте сайт
Потрібна постійна публічна адреса, напр. `https://unimap.example.com/`.
QR-код не можна перевипускати щоразу, тому адресу міняти небажано.

> **Порада.** Якщо домен ще не фінальний — надрукуйте QR на короткий редирект
> (`https://qr.univ.ua/r/55` → ваш сайт). Тоді при зміні домену достатньо
> оновити редирект, а не переклеювати сотні наліпок.

### Крок 2. Згенеруйте коди
Адмін-панель → **🔳 QR-коди аудиторій**:

1. У полі «Адреса сайту» вкажіть базовий URL (за замовчуванням — поточний).
2. Знайдіть потрібні приміщення в пошуку.
3. Позначте галочками (або «Вибрати всі»).
4. Скачайте окремо **SVG** (для друкарні — векторний, будь-який розмір)
   або **PNG**, чи натисніть **🖨 Друкувати аркуш** — сітка 3 в ряд з підписами.

### Крок 3. Надрукуйте і розклейте
- **Мінімальний розмір:** 3×3 см. Для коридору, де сканують з 1–2 м — 8×10 см.
- **Тиха зона:** білі поля навколо коду вже вбудовані в SVG — не обрізайте їх.
- **Висота:** 140–160 см від підлоги, поруч із табличкою номера аудиторії.
- **Захист:** ламінуйте або друкуйте на вініловій наліпці — подряпаний код
  на рівні корекції M ще читається, але краще не ризикувати.
- **Підпис:** обовʼязково лишіть текст «Наведіть камеру — побачите маршрут»,
  інакше люди не розуміють, навіщо код.

### Крок 4. Перевірте
Відскануйте кожен код звичайною камерою телефону. Має відкритись карта з
повідомленням «Ви тут: <назва>».

## 3. Рівень корекції помилок

| Рівень | Відновлює | Коли брати |
|---|---|---|
| L | 7% | код великий, середовище чисте |
| **M** | **15%** | **типовий вибір для приміщень** |
| Q | 25% | людний коридор, код можуть затерти |
| H | 30% | вулиця, вологість, або код із логотипом посередині |

Що вищий рівень — то щільніший код за того самого розміру, тож для дрібного
друку не ставте H без потреби.

---

## 4. Безпека

QR-код — це **недовірений ввід**: будь-хто може роздрукувати свій і наклеїти
поверх вашого. Тому `deepLink.ts`:

- пропускає id через `sanitizeId()` (лишаються тільки літери, цифри, `_ - .`);
- **звіряє значення з каталогом приміщень** — невідоме просто ігнорується;
- обмежує `floor` діапазоном 1–3;
- ловить помилки розбору URL у `try/catch`, тож пошкоджений код не ронить застосунок.

Максимум, що може зробити підроблений QR, — відкрити карту з іншою (існуючою)
стартовою точкою. Ні виконати скрипт, ні зіпсувати стан він не може.

## 5. Масова генерація без інтерфейсу

Якщо треба згенерувати всі коди скриптом (напр. у CI), використайте той самий модуль:

```ts
import { writeFileSync } from 'node:fs';
import { encodeQr, qrToSvg } from './src/utils/qrCode';
import { buildDeepLinkUrl } from './src/utils/deepLink';
import { selectableRooms } from './src/config/positionedElements';

const BASE = 'https://unimap.example.com/';

for (const room of selectableRooms) {
  const url = buildDeepLinkUrl(BASE, room.id);
  const svg = qrToSvg(encodeQr(url, 'M'), { size: 512, caption: room.label });
  writeFileSync(`qr/${room.id.replace(/[^\p{L}\p{N}]+/gu, '_')}.svg`, svg);
}
```

`src/utils/qrCode.ts` не має зовнішніх залежностей (byte-режим, версії 1–10,
рівні L/M/Q/H) — жодного `npm install` не потрібно.

## 6. Типові проблеми

| Симптом | Причина | Рішення |
|---|---|---|
| Код відкривається, але старт не підставився | id у параметрі відсутній у каталозі | Перевірте назву в списку «Звідки»; regenerate код |
| «QR-код вказує на невідоме приміщення» | приміщення перейменували після друку | Перегенеруйте код або поверніть старий id |
| Код не сканується | замалий / низький контраст / обрізана тиха зона | Збільште до 8 см, друкуйте чорним по білому з полями |
| Відкривається не той сайт | базовий URL був неправильний на момент генерації | Перегенеруйте з коректним доменом |
