# Unimap

Інтерактивна карта для зручної внутрішньої навігації територією та корпусами Білоцерківського національного аграрного університету (БНАУ). Додаток допомагає швидко знаходити аудиторії, кафедри, буфети та інші локації.

## Що вміє додаток

* Пошук аудиторій за номером або назвою
* Побудова маршрутів всередині корпусу
* Відображення додаткових об'єктів на карті (буфети, виходи тощо)
* Зручно працює як на комп'ютері, так і на телефоні

## Технології

Проєкт написаний на JavaScript, HTML та CSS. Для оптимізації іконок використовуються SVG-спрайти. Для налаштування середовища та перевірки коду підключені npm та ESLint.

## Як запустити на своєму комп'ютері

Для початку переконайтеся, що у вас встановлений Node.js. Далі виконайте ці кроки у терміналі:

1. Склонуйте репозиторій:
git clone https://github.com/ваше-посилання/unimap.git

2. Зайдіть у папку проєкту:
cd Unimap

3. Встановіть усі залежності:
npm install

4. Запустіть проєкт:
npm run dev (або npm start)

Після цього в терміналі з'явиться посилання (найчастіше це http://localhost:3000 або http://localhost:5173), яке потрібно відкрити в браузері.

## Структура тек

public/ — статичні файли
src/ — вихідний код додатку
src/Sprite/ — SVG-іконки
eslint.config.js — налаштування лінтера
package.json — конфігурація проєкту та залежності
